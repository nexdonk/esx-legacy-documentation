## Installation & Setup

### Quick Installation
All ESX Legacy addons are included in our secondary repository for easy deployment:

**[Download ESX Legacy Addons Repository](https://github.com/esx-framework/esx-legacy-addons)**

### Individual Resource Downloads  
Need specific addons only? Use the **[GitHub Directory Downloader](https://download-directory.github.io/)** to select individual resources.

### Installation Steps
1. Download desired addon(s) from the repository
2. Place in your server's `resources` folder  
3. Add to your `server.cfg` file
4. Import any required database files
5. Configure settings in addon config files
6. Restart your server

## Addon Compatibility

### Framework Requirements
- **ESX Legacy Core** (latest version recommended)
- **MySQL/MariaDB** database
- **FiveM Server** (latest artifacts)

### Dependency Management
Most addons require:
- `es_extended` (core framework)
- `esx_menu_default` (for UI interactions)  
- Additional dependencies listed in each addon's documentation
